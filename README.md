# Vibe Coding Playground

Одностраничный сайт-витрина: анимации, интерактив, визуальные эффекты и адаптивность.

## Стек

Vite + React 19 + TypeScript + Tailwind CSS v4 + Motion.

## Команды

```bash
npm install
npm run dev
npm run build
npm run preview
npm run lint
```

Контекст проекта — в `docs/`.
