\# Vibe Coding Playground — обзор проекта



\## Что это

Одностраничный интерактивный сайт-витрина. Каждый блок показывает одну возможность современной веб-разработки: анимации, интерактив, визуальные эффекты, адаптивность. Подзаголовок на сайте: «Создано за 1 день с помощью Claude и Cursor».



\## Цели

\- Показать, что с помощью нейросетей можно быстро сделать визуально сильный сайт.

\- Вдохновить новичков и опытных разработчиков на вайбкодинг.

\- Служить живым учебным примером для учеников курса: код читаемый, с комментариями.

\- Быть основой, к которой легко добавлять новые блоки.



\## Аудитория

\- Ученики курса по вайбкодингу.

\- Новички, которые хотят понять, на что способны нейросети.

\- Опытные разработчики, которым нужно вдохновение и готовые приёмы.



\## Структура страницы (MVP)

1\. \*\*Hero\*\* — заголовок «Vibe Coding Playground», подзаголовок, анимированный градиентный фон, parallax, плавное появление.

2\. \*\*Animations\*\* — каскадное (stagger) появление карточек, реакция на hover и скролл, возможности Framer Motion.

3\. \*\*Interactivity\*\* — кнопки с конфетти и морфингом, анимированные слайдер и переключатель, живое превью.

4\. \*\*Visual Effects\*\* — glassmorphism, градиенты, свечение, hover-смена цвета.

5\. \*\*Responsive Design\*\* — переключатель desktop / tablet / mobile, контент перестраивается на container queries.

6\. \*\*Footer\*\* — о проекте, ссылка на GitHub, призыв «Хочешь научиться так же? Пройди курс».



\## Стиль

\- Современный, смелый, визуально впечатляющий; дизайн 2025–2026.

\- Тёмная тема по умолчанию + светлая; переключатель в шапке.

\- Яркие неоновые акценты (фиолетовый, циан, розовый) и градиенты.

\- Много «воздуха» между блоками; каждый блок — отдельная визуальная история.

\- Адаптивность для всех устройств.



\## Принципы разработки

\- Один блок = один модуль со своей ответственностью.

\- Новый блок добавляется без правок в других блоках (через реестр секций).

\- Цвета только через токены, анимации только через общие пресеты.

\- Уважать `prefers-reduced-motion`, доступность и производительность.



\## Вне рамок MVP

Бэкенд, авторизация, CMS, мультиязычность, 3D-сцены (возможные будущие блоки).



\## Критерии успеха

\- Первый экран вызывает «вау» в обеих темах.

\- Анимации плавные (около 60 fps) на среднем телефоне.

\- Lighthouse: Performance и Accessibility не ниже 90.

\- Новый блок можно добавить за 3 шага.
